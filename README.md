# Personal Portfolio Website

A responsive one-page portfolio website developed as part of a school project using **Django**, **Bootstrap 5**, **Python**, **HTML**, **CSS**, and **JavaScript**. The project demonstrates the use of the Django framework, Git version control, GitHub repository management, and Bootstrap for responsive web design.

## Features

* One-page portfolio
* Modern gradient user interface
* About Me section
* Projects section
* Contact section
* Bootstrap 5 responsive layout
* Django template inheritance
* Static file management with Django

## Built With

* Python
* Django
* Bootstrap 5 (CDN)
* HTML5
* CSS3
* JavaScript
* Git
* GitHub

## Installation

1. Clone the repository.

```bash
git clone https://github.com/gkurtthomas/portfolio-site.git
```

2. Navigate to the project directory.

```bash
cd Portfolio
```

3. Create and activate a virtual environment.

Windows:

```bash
python -m venv venv
venv\Scripts\activate
```

macOS/Linux:

```bash
python3 -m venv venv
source venv/bin/activate
```

4. Install the required packages.

```bash
pip install -r requirements.txt
```

5. Run the Django development server.

```bash
python manage.py runserver
```

6. Open your browser and visit:

```
http://127.0.0.1:8000/
```
